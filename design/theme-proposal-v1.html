色值对照

每格上行为浅色、下行为深色。高亮列为当前预览方案。语义变量名与产品 tokens.css 一致，落地时可直接替换值。

1现状的问题

  • 浅色底 #f8f6f2 偏黄、深色底 #1e211f 带绿味，与青绿强调色同色系，整体发闷、层次靠 1px 线硬撑。
  • 强调色 #3e7a72 饱和度过低，主按钮与「导入 / 排序」等次要按钮视觉重量几乎相同。
  • 卡片操作按钮默认 opacity:0，只能靠 hover 发现；批量条里的删除是纯文字，看不出危险层级。
  • 深色下 --accent 变亮、--accent-bright 反而更暗，两个 token 的强弱关系在两套主题里是反的。

2这稿改了什么

  • 中性色去色偏：浅色改冷白微蓝，深色改深蓝灰，卡片 / 侧栏 / 内容区三层明差拉开。
  • 强调色提纯：A 用靛蓝 #4f46e5，B 用深青 #0f766e；深色统一翻成高亮版，并新增 --on-accent 保证按钮文字对比度。
  • 按钮四阶梯：Primary 实心 + 内高光 + 彩色投影；Secondary 浅底 + 实边框；Tertiary 幽灵；Danger 常态带浅红底。
  • 操作项常态可见：卡片图标按钮给底色与边框，hover 转强调色；删除转危险色。

3顺带统一的状态与形状

  • 选中卡片：3px 强调色左条 + 2px 柔光描边；选中 chip / 侧栏项：强调色浅底 + 强调色文字 + 左侧指示条。
  • 输入框焦点：强调色边框 + 3px 光晕；圆角按钮 6→8、卡片 8→12、窗口 12→14。
  • 字号、三栏宽度、状态栏高度全部不变，避免牵动已有布局与滚动逻辑。

4落地范围与风险

  • 主要改 assets/styles/tokens.css（变量值 + 新增 --on-accent / --accent-shadow），其次 components.css 的 .btn / .chip / .card__act / .skill-row.is-selected；dialogs.css、editor.css 沿用变量即可。
  • 标题栏品牌图标与 selection-bar 里有硬编码 #6BA8A0，选 A 必须同步；选 B 也建议统一到新值。
  • 来源 / 分类标识色本稿保留原值，避免一次改太多；如要更现代可另出第二稿。
  • 不改 JS、不改结构尺寸，不触碰已验证的主题切换逻辑。
